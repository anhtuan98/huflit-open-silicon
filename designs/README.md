# designs/

Small learning designs run through the full LibreLane RTL -> GDSII flow
(counter, UART, "Hello HUFLIT"). Educational only — no tape-out submission
in the first 12 months (ADR-OS-003).

Each design gets its own subdirectory: `designs/<name>/` with RTL and its
LibreLane config.
