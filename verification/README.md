# verification/

cocotb testbenches against open-source IP — the primary product of this
program (ADR-OS-002). Each effort targets a real upstream project with
missing verification coverage; the goal of each is a merged pull request
upstream, not a testbench that stays local.

Each effort gets its own subdirectory: `verification/<upstream_project>/`.

Empty for now — Phase 0 has not selected a target IP yet (see the candidate
IP shortlist TODO in `backlog.md`).
